# 账号注册审批与登录说明

## 一、整体机制

注册由"自由注册"改为"申请—批准—绑定"三步：

1. 申请人在软件登录页点"注册账号"，填写账号、密码（可填密码提示），提交申请；软件记录本机机器码，并生成一份申请文件。
2. 申请人把申请文件发送到管理员邮箱 **frefire1@hotmail.com**（人工转发，软件不联网发信）。
3. 管理员用《批准码生成器》打开申请文件，生成批准码并发回申请人。
4. 申请人在软件里输入批准码，软件核对通过后完成注册，账号与此电脑硬件绑定。

批准码格式为 **账号 + 86 位签名串**，由管理员离线私钥签名；软件安装包内只有公钥，只能验签、不能签发。批准码与账号、机器码、申请编号绑定，因此：换账号、换电脑、换申请编号都会导致批准码失效——只有该申请人在其本人电脑上、该次申请中才能使用。

> 重要：保护升级后，旧版「12 位纯数字」批准码全部作废。请让管理员用新版生成器重新签发批准码。

> 注册与"忘记密码重置"共用同一批准码。请妥善保存批准码。

## 二、申请人操作（软件端）

1. 打开软件进入登录页，点"注册账号"，填写账号、密码、确认密码；建议填写**密码提示**（忘记密码时会显示，用于自我提醒，请勿直接写出密码）。
2. 点"提交注册申请"，界面显示账号、机器码、申请编号和管理员邮箱。点"导出申请文件"保存 JSON 文件，点"复制邮箱地址"取邮箱。
3. 把申请文件作为附件发送到 frefire1@hotmail.com，等待管理员发回批准码。
4. 收到批准码后回到软件，在"批准码"输入框填入，点"核对并注册"。
5. 核对通过即进入工作台；此后在该电脑用账号+密码登录。如需放弃本次申请，可点"撤销申请"。

## 三、登录与记住密码

- 登录页有"**记住账号和密码**"勾选框。勾选后，本机会用与硬件绑定的密钥加密保存登录凭据，下次启动自动填入账号与密码；取消勾选后不再保存。凭据仅在本机、本账号下有效，账号或电脑不匹配时自动失效。
- 一台电脑仅绑定一个账号；已注册后再点"注册账号"会提示无法在本机重复注册。

## 四、忘记密码与批准码重置

1. 在登录页点"忘记密码？"，输入本机注册的账号，点"查看密码提示"。
2. 界面显示注册时填写的密码提示、机器码、申请编号和管理员邮箱。
   - 若你还保留注册时的批准码，可直接用于下一步重置。
   - 若批准码遗忘，把账号、机器码、申请编号发到 frefire1@hotmail.com，管理员用生成器重新生成批准码。
3. 输入批准码、新密码、确认新密码，按需勾选"记住账号和新密码"，点"重置密码"。
4. 核对通过后自动解锁进入工作台；此后用新密码登录，旧密码失效。重置会清除之前记住的凭据（若勾选则保存新密码）。

## 五、管理员操作（批准码生成器）

1. 打开《批准码生成器》目录中的 `批准码生成器.html`（双击即可离线使用，无需安装、无需联网）。
2. 点"导入申请文件"，选择申请人发来的 JSON 文件，账号、机器码、申请编号会自动填入。
3. 点"生成批准码"，得到形如 `账号+86位签名串` 的批准码，可"复制"后发回申请人。忘记密码重置时同样用此码，无需重新生成（除非申请人遗失了原批准码）。
4. 如需要，可点"核对有效性"确认批准码与该申请信息匹配。

> 也可在"手动填写"区直接录入账号、机器码、申请编号生成批准码。

## 六、重要文件

| 文件 | 用途 |
| --- | --- |

| `批准码生成器/approval-private.js` | 管理员私钥，**不得随软件发给申请人，也不要删除**；丢失后无法为新申请签发批准码 |

## 七、验证情况

- 批准码改为 ECDSA P-256 非对称签名：软件只内置公钥，生成器持私钥；同一申请在 Node 与浏览器端均可正确签发，软件端验签通过。
- 错误批准码、错误账号、换电脑、换申请编号均被拒绝；发布版压缩脚本下的申请→签发→注册→登录→找回→重置全流程端到端通过。
- 发布资源生成带签名的完整性清单；任一前端/服务端脚本被改动都会被拒绝启动，已实测篡改检测有效。
- 第一方 JS 已在发布包中压缩处理；安装包内不再包含任何可用于自行签发批准码的密钥或共享口令。
- Electron 关闭 DevTools、远程调试端口与右键菜单，并清理注入型环境变量；Node 服务拒绝调试模式启动；macOS 端关闭 Web Inspector 并做同样完整性校验。
- macOS 应用实际启动、Node 审批服务正常加载，签名与双架构校验通过。Windows 便携包已构建并校验内部完整性，真机运行仍建议你实际打开确认。

> 安全提醒：新版批准码不能由软件自行生成。请只把两个 zip 安装包发给申请人；`批准码生成器` 整个目录（尤其 `approval-private.js`）仅管理员自己保管。旧版 12 位批准码已作废。
